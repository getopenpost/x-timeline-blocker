# X Timeline Blocker

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Svelte 5, Chromium and Firefox MV3, shared OpenPost UI and Dither packages. Backendless.

## Product purpose

Pause X and Twitter home timelines. Explicit Browse timeline grants five minutes. The next grant opens one hour after the previous grant. One timer applies across tabs and browser restarts.

## Capabilities and constraints

Keep posting, compose, DMs, notifications, profiles, bookmarks and individual posts available. Store only the timer locally. No accounts, telemetry, remote code or operator service.

## Brand commitments

OpenPost attribution replaces Post Bridge. Use OpenPost's orange Dither family and the system light/dark scheme. The popup and timeline gate have a timer, one next action and an unobtrusive OpenPost link. No feature lectures or boilerplate disclaimers.

## Evidence on hand

The user pinned the minimal UI and the reference behavior of Post Bridge's X Timeline Blocker. Fixture tests prove packaged behavior. Live X changes remain a compatibility boundary.
